# CS2 DMA Aimbot

A CS2 DMA (Direct Memory Access) utility for aimbot functionality that reads memory from game DLLs to make aim corrections with MAKCU device.

## Building

To build the project:

Run the Build file.

## Features

- Offsets are pulled from github automatically.
- COM port selection for MAKCU device.
- FOV selection
- Sensitivity Selection

## Usage

After building with `build release -r`, or Build file, use the tool to inject into your CS2 session for aimbot functionality.
